<div dir="rtl" class="long-text">
<p>التالي عبارة عن كود CSS احترافي ومتقدم جداً مخصص لإدارة خط&nbsp;<strong>"المهند" (AL-Mohanad)</strong> بطريقة ذكية ومتناسقة للغاية.</p>
<h3>أولاً: تحليل المعلومات الواردة في الكود</h3>
<p><span style="background-color: #ffff99;">تم تقسيم الكود إلى قسمين رئيسيين لضمان التوافق والمظهر البصري المثالي</span>:</p>


<img src="https://44kg.com/images/post_img/AL-Mohanad.jpg">
<ol>
<li class="long-text">
<p><strong>قسم الحروف العربية (<code>AL-Mohanad</code> للغة العربية):</strong></p>
<ul>
<li>
<p><strong>مصدر الخط (<code>src</code>):</strong> يعتمد على صيغة <code>woff2</code> الحديثة والسريعة التحميل من المسار المحلي <code>images/fonts/ALMohanad/</code>.</p>
</li>
<li>
<p><strong>الأوزان (<code>font-weight</code>):</strong> معرّف بثلاثة أوزان (عادي <code>400</code>، وشبه عريض <code>600</code>، وعريض <code>700</code>).</p>
</li>
<li>
<p><strong>معامل تعديل الحجم (<code>size-adjust: 125%</code>):</strong> ميزة حديثة ورائعة تقوم بتكبير الحروف العربية بنسبة 25% تلقائياً عند عرضها، لكي تتطابق بصرياً مع الحروف الإنجليزية والرموز.</p>
</li>
<li>
<p><strong>نطاق الرموز (<code>unicode-range</code>):</strong> يوجه المتصفح لاستخدام خط "المهند" فقط للنطاقات العربية والإسلامية والعثمانية (مثل الحروف الأساسية، والتشكيل، والحروف الخاصة).</p>
</li>
</ul>
</li>
<li class="long-text">
<p><strong>قسم الحروف اللاتينية والأرقام (Fallback System Fonts):</strong></p>
<ul>
<li>
<p><strong>المصدر (<code>src</code>):</strong> بدلاً من تحميل ملف خط إنجليزي منفصل وحجمه ثقيل، يستخدم الخطوط المتوفرة أصلاً في جهاز المستخدم (<code>Segoe UI</code>، ثم <code>Helvetica Neue</code>، ثم <code>Arial</code>).</p>
</li>
<li class="long-text">
<p class="long-text"><strong>موازنة الحجم (<code>size-adjust: 88%</code>):</strong> بما أن خط المهند يبدو كبيراً بطبيعته، يتم تصغير الحروف الإنجليزية والأرقام بنسبة تقارب 12% (<code>88%</code>) لكي تتماشى وتتوازن تماماً مع سطر الحروف العربية بجانبها دون أن تبدو ضخمة أو نشازاً.</p>
</li>
<li>
<p><strong>نطاق الرموز (<code>unicode-range</code>):</strong> يخصص هذه الخطوط فقط للغة الإنجليزية، اللاتينية، الرموز، وعلامات الترقيم (<code>U+0000-024F</code> وماها شابه).</p>
</li>
</ul>
</li>
</ol>
<h3>ثانياً: هل بالإمكان اختصاره؟</h3>
<p><strong>نعم، وبشكل كبير جداً!</strong></p>
<p>الكود الحالي مكرر لأن أوزان <code>600</code> و <code>700</code> تستخدم نفس ملف الخط العريض (<code>AL-Mohanad-Bold-v11.woff2</code>). كما يمكن دمج بعض الخصائص المشتركة.</p>
<p>إليك النسخة <strong>المختصرة والنظيفة</strong> التي تؤدي تماماً نفس الأداء وبأقل عدد ممكن من الأسطر:</p>
<div class="long-text">
<div class="long-text">
<div class="long-text">
<div>CSS</div>
<pre><code>/* --- 1. الحروف العربية لخط المهند --- */
@font-face {
 font-family: 'AL-Mohanad';
 src: url('/images/fonts/ALMohanad/AL-Mohanad-Regular-v11.woff2') format('woff2');
 font-weight: 400;
 font-display: swap;
 size-adjust: 125%;
 unicode-range: U+0600-06FF, U+0750-077F, U+0870-089F, U+08A0-08FF, U+FB50-FDFF, U+FE70-FEFF;
}
@font-face {
 font-family: 'AL-Mohanad';
 src: url('/images/fonts/ALMohanad/AL-Mohanad-Bold-v11.woff2') format('woff2');
 font-weight: 600 700; /* دمج الوزن 600 و 700 في سطر واحد */
 font-display: swap;
 size-adjust: 125%;
 unicode-range: U+0600-06FF, U+0750-077F, U+0870-089F, U+08A0-08FF, U+FB50-FDFF, U+FE70-FEFF;
}
/* --- 2. الحروف اللاتينية والأرقام (نظام التشغيل) --- */
@font-face {
 font-family: 'AL-Mohanad';
 src: local('Segoe UI'), local('Helvetica Neue'), local('Arial');
 font-weight: 400;
 font-display: swap;
 size-adjust: 88%;
 unicode-range: U+0000-024F, U+0370-03FF, U+2000-206F, U+2070-209F, U+20A0-20CF;
}
@font-face {
 font-family: 'AL-Mohanad';
 src: local('Segoe UI Bold'), local('Helvetica Neue Bold'), local('Arial Bold');
 font-weight: 600 700; /* دمج الوزن العريض للغات الأجنبية أيضاً */
 font-display: swap;
 size-adjust: 88%;
 unicode-range: U+0000-024F, U+0370-03FF, U+2000-206F, U+2070-209F, U+20A0-20CF;
}
</code></pre>
</div>
</div>

<h3>التعديلات التي تمت في الاختصار:</h3>
<ul>
<li class="long-text">
<p class="long-text">تم دمج كتل الأوزان (<code>600</code> و <code>700</code>) باستخدام النطاق <code>font-weight: 600 700;</code> لأنها تشترك في نفس الملف والخصائص، مما قلل حجم الكود إلى النصف تقريباً وجعله أسهل في القراءة والصيانة مع الحفاظ على التوازن الجمالي الرائع الذي أعجبك.</p>
</li>
</ul>
