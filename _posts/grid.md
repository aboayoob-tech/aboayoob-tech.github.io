#### الـ `Grid` (الشبكة) 

هو نظام تنظيم ثنائي الأبعاد يعتمد على صفوف وأعمدة لترتيب وتوزيع العناصر بدقة ومرونة، سواء في تصميم الواجهات أو في برمجة وتطوير مواقع الويب.

1. مفهوم الـ [^Grid]**Grid**  في التصميم (Design Grid Systems)\
**التعريف**: هو هيكل أو إطار غير مرئي مكون من خطوط أفقية ورأسية متقاطعة.الأهمية: يساعد المصممين على ترتيب الصور والنصوص والعناصر بطريقة متوازنة ومريحة للعين.\
**الاستخدام** : يُستخدم بكثرة في تصميم المجلات، الصحف، وتطبيقات الهواتف والمواقع لضمان ثبات الشكل العام وتناسقه.

2. **مفهوم الـ `Grid`** في البرمجة (CSS Grid)\
**التعريف** : هي خاصية في لغة CSS تتيح لك تقسيم مساحة صفحة الويب إلى صفوف وأعمدة لتحكم كامل بموقع وحجم العناصر.

*   **طريقة التفعيل** : يتم تحويل أي عنصر إلى حاوية شبكية عبر كتابة:`display: grid`

*   **خصائص أساسية** : `grid-template-columns` : لتحديد عدد وحجم الأعمدة (مثل استخدام وحدة `fr` لتوزيع المساحات المتاحة).
   * **`gap`** : لتحديد المسافات الفاصلة (الفراغات) بين العناصر وبعضها.

*   **الفرق بينه وبين**  `Flexbox:Flexbox` : نظام أحادي البعد (إما أفقياً أو عمودياً).
    * **`Grid`** : نظام ثنائي البعد (أفقياً وعمودياً في نفس الوقت، يشبه الجدول المرن).

* * *
المصطلحات الأساسية في نظام CSS Grid
*   **حاوية الشبكة (Grid Container)**: العنصر الأب الذي يتم تطبيق الخاصية `display: grid;` عليه.
*   **عناصر الشبكة (Grid Items)**: العناصر الأبناء المباشرين داخل الحاوية.
*   **خطوط الشبكة (Grid Lines)**: الخطوط الأفقية والعمودية التي تقسم الشبكة وتُستخدم لترتيب العناصر بناءً على أرقامها.
*   **مسارات الشبكة (Grid Tracks)**: المسافة بين أي خطين متتاليين في الشبكة (أي العمود الكامل أو الصف الكامل).
*   **خلايا الشبكة (Grid Cell)**: المساحة المحصورة بين 4 خطوط شبكة متقاطعة (وهي أصغر وحدة في الشبكة، تشبه خلية الإكسل).
*   **مناطق الشبكة (Grid Area)**: مساحة مجمعة تتكون من عدة خلايا شبكة معاً لتشكيل منطقة مخصصة (مثل منطقة الهيدر أو القائمة الجانبية).
*   **الفجوات (Grid Gaps/Gutters)**: المسافات الفارغة الفاصلة بين الأعمدة والصفوف.
الخصائص البرمجية الأساسية وكيفية ترجمتها واستخدامها
    1. خصائص الحاوية (Container Properties)

      *  `display: grid;`: تحويل العنصر إلى حاوية شبكة.
      *  `grid-template-columns:` تحديد عدد الأعمدة وعرض كل عمود. 
       (مثال: `grid-template-columns: 200px 1fr 1fr;` تعني ثلاثة أعمدة).
      *  `grid-template-rows`: تحديد عدد الصفوف وارتفاع كل صف.
      *  `grid-gap` (أو `gap`): لتحديد حجم الفراغات بين الصفوف والأعمدة.

    2. خصائص العناصر الداخلية (Item Properties)

      *  `grid-column-start` / `grid-column-end`: تحديد الخط الذي يبدأ عنده العنصر والخط الذي ينتهي عنده أفقياً.
      *  `grid-row-start` / `grid-row-end`: تحديد خط البداية والنهاية للعنصر عمودياً.
 
 
* * *
```
<div class="grid-container">
  <header class="header">العنوان الرئيسي (Header)</header>
  <aside class="sidebar">الشريط الجانبي (Sidebar)</aside>
  <main class="main-content">المحتوى الرئيسي (Main Content)</main>
  <footer class="footer">الفوتر / أسفل الصفحة (Footer)</footer>
</div>

/* تفعيل نظام الشبكة على الحاوية الرئيسية */
.grid-container {
  display: grid;
  /* تحديد 3 أعمدة: الجانبي يأخذ 200px، والمحتوى يأخذ المساحة المتبقية 1fr */
  grid-template-columns: 200px 1fr 1fr;
  /* تحديد ارتفاع الصفوف تلقائياً حسب المحتوى */
  grid-template-rows: auto auto auto;
  /* تسمية مناطق الشبكة لتوزيع العناصر بسهولة */
  grid-template-areas: 
    "header header header"
    "sidebar main main"
    "footer footer footer";
  /* إضافة مسافة 15 بكسل بين العناصر */
  gap: 15px; 
  padding: 15px;
  font-family: sans-serif;
}

/* ربط كل عنصر بالمنطقة المخصصة له في الشبكة */
.header {
  grid-area: header;
  background-color: #34495e;
  color: white;
  padding: 20px;
  text-align: center;
}

.sidebar {
  grid-area: sidebar;
  background-color: #ecf0f1;
  padding: 20px;
  min-height: 200px;
}

.main-content {
  grid-area: main;
  background-color: #3498db;
  color: white;
  padding: 20px;
}

.footer {
  grid-area: footer;
  background-color: #2c3e50;
  color: white;
  padding: 15px;
  text-align: center;
}
```
💡 **شرح فكرة الكود ببساطة**:\
تم تقسيم الصفحة تخيلياً إلى 3 أعمدة.
*   **السطر "header header header"** يعني أن الهيدر سيمتد ليغطي الـ 3 أعمدة كاملة في الصف الأول.
*   **السطر "sidebar main main"** يعني أن الشريط الجانبي سيأخذ العمود الأول، والمحتوى الرئيسي سيأخذ العمودين الثاني والثالث في الصف الثاني.
*   **السطر "footer footer footer"** يجعل الفوتر يمتد على كامل العرض في الصف الأخير.


#### 💡 مقارنة بين نظامين أساسيين في CSS

**غالبًا ما يخلط المبتدئين بين نظام CSS Grid ونظام Flexbox.**

| وجه المقارنة      | نظام شبكة CSS (Grid)                          | نظام الصندوق المرن (Flexbox)                       |
|-------------------|-----------------------------------------------|----------------------------------------------------|
| الأبعاد           | ثنائي الأبعاد (يعمل على الصفوف والأعمدة معاً) | أحادية البعد (يعمل على صف واحد أو عمود واحد فقط)   |
| الاستخدام الأساسي | لتصميم الهيكل الخارجي العام للموقع بأكمله     | لتصميم العناصر الداخلية المحاذية (مثل شريط التنقل) |
|التحكم بالترتيب  | من الأعلى إلى الأسفل ومن اليمين إلى اليسار بالتوازي | في اتجاه خطي واحد|
